torabo-tsuki LP (L) キーマップ

右トラックボール・左に高分解能ダイヤル。Keyball61-Dual の配置を移したもの。キーの位置は実機の配置どおりです。記号は ⌃ Ctrl / ⇧ Shift / ⌥ Alt(Option) / ⌘ Win(Command)。

修飾キー・ショートカット レイヤー切替(長押し) マウス 接続・Bluetooth このレイヤー中に押さえているキー 割り当てなし

ダイヤルを押すと縦スクロールと横スクロールが切り替わります(Layer 1 HScroll のオン・オフ)。横のときもキーは Base と同じです。

空欄のキーは下のレイヤー(Base)と同じ動作です。Keyball61 のマクロ位置は未割当です。

左 ⌘ を単独で押すと英数、右 ⌘ を単独で押すとかなになるのは Mac の Karabiner-Elements の設定によるもので、キーボード側の設定ではありません。

設定ファイル: fukayatsu/zmk-keyboard-torabo-tsuki-lp の config/keymap.keymap(ダイヤルのスクロール速度は 48 1)。
