# torabo-tsuki LP (L) ラップキット

公式シンプルケース (L サイズ、左 key / 右 trackball) を膝の上で安定して使うためのオプションパーツ。

- **ウェッジ (左右)**: ケースの下に既存の M2 ネジ穴で共締めする、一様な厚さ (5.4 mm、置き場部分と同じ) の板。左右はハの字 (片側 8°) に配置し、奥側で約 26 mm 離す。手前にパームレスト置き場を一体で持ち、1 部品で印刷する。
- **ヒンジ**: スガツネ HG-TS03 (トルクヒンジ 0.35 N·m、フリーストップ) 2 個を同じ軸に前後に並べ、左右のウェッジの底を直接つなぐ (1 個よりねじれ・がたつきに強い)。羽根をウェッジ底面に面一で埋め、M4 ボルトと袋ナットで留める。袋ナットはケースの外 (左右の間) のウェッジ上面に座金を挟んで置くので、ウェッジの内側に張り出しを付けてある (張り出しの奥は左右のケースの間のへこみを埋め、ケースの奥の辺をそのまま中心線まで延ばした直線でつなぐ。手前の付け根のへこんだ角は R15 で滑らかにつなぐ。内側の縁 (当たり面) の前後の角は R5 で丸める (たたんだとき上に来る角))。軸は中心線上で底面より下にあるので、左右の外側を下へ折ると底面どうしが向き合う形にぶつからずたためる。どの角度でもその場で止まる。使うときは片側 8° のテンティング (内側が上がる) になる: ヒンジ付近の左右の内側の面 (当たり面) を、軸を通り 8° たたんだときに中心面と重なる面にしてあるので、8° で左右がぴったり当たり、平らな側へは戻らない (内側を手で押す力は当たり面が受ける)。たたむ方向 (8〜90°) は自由。
- **パームレスト置き場**: パームレスト (エレコム MOH-FTRBK 想定, W80×D60×H18, 角 R3) を両面テープで貼る平らな板。上から見た外形はパームレストと同じ (くぼみ・縁なし)。ウェッジ手前面からパームレストの奥の辺まで約 39 mm (中心で、回転前。2026-11-11 に一体印刷のため 25 mm 奥へ移動)、ウェッジよりさらに 5° ハの字に開く (外側へ約 5 mm はみ出す)。ウェッジとは間を埋めてつなぐ: 内側はケース手前の内側の角からパームレスト手前の内側の角へ、外側はケース手前の外側の角からパームレスト奥の外側の角へまっすぐ (ケース手前の帯とパームレストの凸包)。置き場部分の厚さは 5.4 mm。

## 寸法

| 項目 | 値 |
|---|---|
| 傾き | 使用時に片側 8° のテンティング (ヒンジの角度で付ける。`use_th`。2026-11-12 に 5° から変更)。外側の縁は内側より約 28 mm 低い |
| ハの字 (片側) | 8° |
| 左右の最接近 (奥側) | ケースどうし約 26 mm。ウェッジの張り出しは使用時に当たり面で接する |
| ウェッジ | 200.4 × 211.7 mm (置き場一体、ハの字の向きのまま)。厚さ 5.4 mm で全体が同じ高さ |
| ヒンジ | HG-TS03 2 個、中心 y = −35 と −85 (間隔 50 mm)。張り出しは 2 個をまたぐ 1 枚。M4 ボルト + 座金 + 袋ナット (上面に置き、スパナで押さえて締める。上面から 11〜13 mm 出る)。軸は底面の 3.05 mm 下、軸筒は底から約 6.8 mm 出る |
| たたみ | 片側 8° (使用時、当たり面で止まる) 〜 90° (底面どうしが向き合う) で干渉なし。羽根・ネジ頭・袋ナット込み |
| パームレスト置き場 | 80 × 60 mm、角 R3 (パームレストと同じ外形、平ら) |

## 部品

| 部品 | 数 |
|---|---|
| `stl/wedge_L.stl`, `stl/wedge_R.stl` (置き場一体) | 各 1 |
| スガツネ HG-TS03 | 2 |
| M4×10 トラス小ねじ (ヒンジ用、なべでも可) | 8 |
| M4 袋ナット (二面幅 7、ネジ穴の深さ 4 mm 以上) | 8 |
| M4 平座金 (小形、外径 8) | 8 |
| M2×6 なべ小ねじ (元の M2×3.5 と交換) | 8 |
| 3M しっかりつくクッションゴム CS-01 (丸形 Ø7.9 × 2.2) | 6 |
| 両面テープ (パームレストの固定) | 適量 |

`stl/coupon_L.stl`, `stl/coupon_R.stl` はヒンジ取付部 (奥のヒンジ 1 個分) だけのテスト片。2 個とも同じ形。HG-TS03 の羽根のはまり具合とボルトの通りを確認する。

HG-TS03 の寸法はメーカーの図による: 全長 32・開いた幅 36・穴ピッチ 18 (軸方向) × 21 (軸をまたぐ方向)・穴 Ø4.3・板厚 1.2・軸筒 Ø7.5・取付面から軸まで 4.25 (2026-11-12 に写真からの推定値 30・34・18 × 20 を修正)。掘り込みはまわりに 0.3 mm のすきま (`hn_clr`)。

ネジが M2×5 では足りないのは、ケース底面のネジ穴に Ø5×0.7 mm の座ぐりがあり、元のネジの頭がその中に沈んでいるため (ウェッジ越しだと 1.5 + 0.7 mm 余分に要る)。

## 印刷

- PLA。STL はそのまま印刷できる向きで書き出してある (サポート不要)。
- ウェッジは上面 (ケースが載る面・置き場) をベッド側に、ハの字の向きのまま置く (200.4 × 211.7 で 220 × 220 のベッドに入る。STL はこの向きで書き出してある)。ケースとの合わせ面とパームレストを貼る面が一番平らになり、ヒンジの掘り込み (幅約 18 × 長さ 33)・軸筒の逃げ・ネジ頭の座ぐりは上向きに開くので、羽根の当たり面もブリッジにならず平らに出る。クッションゴムのくぼみも上向き。ブリッジは無い。凹凸のないベッドシート推奨 (両面テープの貼り付きのため)。
- テスト片も本番と同じ向き (上面が下)。
- どの部品もサポート不要。

## 組み立て

1. ケースの皿ネジを外し、ウェッジを M2×6 で共締め。
2. ヒンジを付ける: 左右のウェッジを並べ、底の掘り込みに HG-TS03 2 個の羽根をはめ (軸筒が外向き)、M4×10 トラス小ねじ 8 本を下から通す。上面に出た先に座金と袋ナットを付け、袋ナットを 7 mm のスパナで押さえて下からドライバーで締める (ボルトの先は座金の上 3.8 mm で、袋ナットのネジ穴が 4 mm 以上の深さなら奥に当たらない。M4×12 は当たるおそれがある)。スパナは柄を中心線側 (ケースと反対) に向けて掛ける (座金とケースの壁のすきまは奥のヒンジで約 2 mm、手前で約 4 mm)。PLA を挟むので締めすぎない。緩み止め剤を推奨。トラス頭を推奨 (なべ頭より低く、全部たたんだとき向き合うネジ頭どうしのすきまが広い。なべ頭でも付くが、たたんだときのすきまは約 0.5 mm)。
3. クッションゴム CS-01 を底のくぼみ (Ø8.5 × 深さ 0.5、片側 3 か所: 奥の外側の角・外側の縁のケース手前寄り・置き場の手前外側の角) に貼る。ゴムは底から 1.7 mm 出る。テンティングで外側が下がるので、机に届くのはこの外側の縁だけで、軸筒 (底から 6.8 mm) は浮く。
   ※ 平らに並べた状態では左右の当たり面が上面で約 1.2 mm ずつ重なるので、ヒンジを付けるときは真ん中を少し持ち上げて 8° に開いた形で並べる。
4. パームレストを置き場の外形に合わせ、両面テープで貼る。
5. たたむ: パームレストは付けたまま、左右の外側を下へ折って底面どうしを合わせる (パームレストは外向きになり、どこにもぶつからない)。

## モデルの編集

[OpenSCAD](https://openscad.org/) (Manifold バックエンド) で `lap_kit.scad` を開く。公式ケースの STL を参照するので、先に公式リポジトリを `official/` に clone しておく。

```sh
git clone https://github.com/sekigon-gonnoc/torabo-tsuki-lp official
```

調整パラメータは `lap_kit.scad` 先頭 (`splay`, `x_off`, `hn_*`, `pr_back` など)。`x_off` は袋ナット・座金がケースに掛からない値 (Ø9 の座金でも当たらない)。`part` で書き出す部品を選ぶ。

```sh
python3 build_preview.py --stl   # stl/ を書き出し直し、build/lap-kit-preview.html を作る
```

### 確認用スクリプト

- `chk_fold.scad`: ヒンジでたたむときの干渉。`th` はたたむ角度 (既定は使用時の `use_th` = 8。それ未満は当たり面が食い込む)、`mode` は `mid` (中心面の反対側) か `pair` (左右どうし)。`hinge=true` で丁番の羽根・ネジ頭も含める。
- `gap.sh <x_off>`: 平らに並べたときの左右の最接近距離 (当たり面が重なるので今は 0。ケースどうしを見るときに使う)。

```sh
openscad -D 'part="none"' -D 'side="R"' -D th=45 -D 'mode="mid"' -o /tmp/chk.stl chk_fold.scad
```

(`-D 'part="none"'` を付けないと、include した `lap_kit.scad` の組み立て図も一緒に出力される)
