# torabo-tsuki LP (L) ラップキット

公式シンプルケース (L サイズ、左 key / 右 trackball) を膝の上で安定して使うためのオプションパーツ。

- **ウェッジ (左右)**: ケースの下に既存の M2 ネジ穴で共締め。奥が 5° 上がり、左右はハの字 (片側 8°)。
- **ブリッジ**: 2 つのピル形を中心でつないだブーメラン形。全周の 45° フランジが、ウェッジ底面ポケットの溝に入るスライドロック。Ø8×2 磁石でロック位置を保持。

## 寸法

| 項目 | 値 |
|---|---|
| 前後の傾斜 (奥が上) | 5° (テンティングなし) |
| ハの字 (片側) | 8° |
| 左右の最接近 (奥側) | 2.2 mm |
| ウェッジ厚 手前 → 奥 | 3.0 → 13.4 mm |
| ブリッジ | 106.9 × 51.2 × 5 mm |
| フランジ | 全周、張り出し 2.5 mm / 下面 45° |
| ポケット・溝すきま | 0.15 mm (0.2 はゆるかった) |
| スライド量 | 約 32 mm (約 30 mm で外れる) |

## 部品

| 部品 | 数 |
|---|---|
| `stl/wedge_L.stl`, `stl/wedge_R.stl` | 各 1 |
| `stl/bridge.stl` | 1 |
| M2×6 なべ小ねじ (元の M2×3.5 と交換) | 8 |
| ネオジム磁石 Ø8×2 | 4 (ブリッジ 2、ウェッジ各 1) |
| 2 液性エポキシ | 少量 |

`stl/coupon_L.stl`, `stl/coupon_R.stl` はポケットまわりだけのテスト片。ブリッジと組んで嵌合を確認する。

ネジが M2×5 では足りないのは、ケース底面のネジ穴に Ø5×0.7 mm の座ぐりがあり、元のネジの頭がその中に沈んでいるため (ウェッジ越しだと 1.5 + 0.7 mm 余分に要る)。

## 印刷

- PLA。STL はそのまま印刷できる向きで書き出してある (サポート不要)。
- ウェッジはケースが当たる平らな面をベッド側に。ポケット・ザグリ・磁石穴は上向き。
- ブリッジは磁石穴を上に。フランジ下面は 45°。
- ウェッジの膝側 (印刷時の上面) は 5° のゆるい斜面なので、スライサーで「垂直シェルの厚さを確保」をオン、上面シェル 6〜8 層 / 1.2 mm 以上にしないとインフィルが透ける。

## 組み立て

1. ケースの皿ネジを外し、ウェッジを M2×6 で共締め。
2. 磁石をエポキシで接着。対の磁石の間にフィルムを挟み、ロック位置にはめた状態で硬化させると極性・面・位置が揃う。
3. ブリッジを左ウェッジに付ける: ブリッジの左端をポケットの内側の口に当て、約 32 mm 左へスライド。
4. 右半身をブリッジの右端に合わせて置き、約 32 mm 左へスライド。外すときは右へ引き抜く。

## モデルの編集

[OpenSCAD](https://openscad.org/) (Manifold バックエンド) で `lap_kit.scad` を開く。公式ケースの STL を参照するので、先に公式リポジトリを `official/` に clone しておく。

```sh
git clone https://github.com/sekigon-gonnoc/torabo-tsuki-lp official
```

調整パラメータは `lap_kit.scad` 先頭 (`pitch`, `splay`, `clr` など)。`part` で書き出す部品を選ぶ。

```sh
python3 build_preview.py --stl   # stl/ を書き出し直し、build/lap-kit-preview.html を作る
```

### 確認用スクリプト

- `chk.scad`: ブリッジと片側ウェッジの干渉。`t` はスライド量、`lift` は持ち上げ量。結果が空なら干渉なし。
- `chk2.scad`: 同じく、内側辺まわりに `rot` 度回したとき。
- `gap.sh <x_off>`: 左右の最接近距離。

```sh
openscad -D 'part="none"' -D 'side="R"' -D t=30 -D lift=0.6 -o /tmp/chk.stl chk.scad
```

(`-D 'part="none"'` を付けないと、include した `lap_kit.scad` の組み立て図も一緒に出力される)
