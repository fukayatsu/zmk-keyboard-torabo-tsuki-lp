# torabo-tsuki LP (L) ラップキット

公式シンプルケース (L サイズ、左 key / 右 trackball) を膝の上で安定して使うためのオプションパーツ。

- **ウェッジ (左右)**: ケースの下に既存の M2 ネジ穴で共締めする、一様な厚さ (8.65 mm) の水平な板。左右はハの字 (片側 8°) に配置。
- **ブリッジ**: 2 つのピル形を中心でつないだブーメラン形。全周の 45° フランジが、ウェッジ底面ポケットの溝に入るスライドロック。
- **プレート (左右)**: パームレスト (サンワ TOK-MU2NBK2, W94×D80×H21) の置き場。全周フランジ付きの舌片を、ウェッジ手前のポケットに前から差し込む。
- Ø8×2 磁石でロック位置を保持。

## 寸法

| 項目 | 値 |
|---|---|
| 傾き | なし (水平) |
| ハの字 (片側) | 8° |
| 左右の最接近 (奥側) | 2.25 mm |
| ウェッジ厚 | 8.65 mm (ブリッジ 5.4 + すきま 0.15 + 磁石穴 2.1 + 天井 1) |
| ブリッジ | 105.8 × 50.4 × 5.4 mm |
| フランジ | 全周、張り出し 2.0 mm。断面は 垂直 1.4 → 45° 2.0 → 垂直 2.0 |
| ポケット・溝すきま | 0.15 mm (0.2 はゆるかった) |
| ブリッジのスライド | 約 32 mm (約 30 mm で外れる) |
| プレート | 100.8 × 121.3 mm、厚さ 3 mm、縁の高さ 6 mm |
| パームレスト置き場 | 96 × 82 mm (片側 1 mm のすきま)、角 R8 |
| プレートのスライド | 約 36 mm (約 34 mm で外れる) |

## 部品

| 部品 | 数 |
|---|---|
| `stl/wedge_L.stl`, `stl/wedge_R.stl` | 各 1 |
| `stl/bridge.stl` | 1 |
| `stl/plate_L.stl`, `stl/plate_R.stl` | 各 1 |
| M2×6 なべ小ねじ (元の M2×3.5 と交換) | 8 |
| ネオジム磁石 Ø8×2 | 8 (ウェッジ 4、ブリッジ 2、プレート 2) |
| 2 液性エポキシ | 少量 |

`stl/coupon_L.stl`, `stl/coupon_R.stl` はブリッジ用ポケットまわりだけのテスト片。ブリッジと組んで嵌合を確認する (プレートの舌片も同じ断面)。

ネジが M2×5 では足りないのは、ケース底面のネジ穴に Ø5×0.7 mm の座ぐりがあり、元のネジの頭がその中に沈んでいるため (ウェッジ越しだと 1.5 + 0.7 mm 余分に要る)。

## 印刷

- PLA。STL はそのまま印刷できる向きで書き出してある (サポート不要)。
- ウェッジはケースが当たる平らな面をベッド側に。ポケット・ザグリ・磁石穴は上向き。
- ブリッジは磁石穴を上に。プレートは底面をベッド側に。フランジ下面は 45°。

## 組み立て

1. ケースの皿ネジを外し、ウェッジを M2×6 で共締め。
2. 磁石をエポキシで接着。ウェッジ側はポケット天井のくぼみ (ケース側に 1 mm 残す)。対の磁石の間にフィルムを挟み、ロック位置にはめた状態で硬化させると極性・面・位置が揃う。
3. ブリッジを左ウェッジに付ける: ブリッジの左端をポケットの内側の口に当て、約 32 mm 左へスライド。
4. 右半身をブリッジの右端に合わせて置き、約 32 mm 左へスライド。外すときは右へ引き抜く。
5. プレート: 舌片をウェッジ手前面の溝の口に合わせ、奥へ約 36 mm 差し込む。外すときは手前へ引き抜く。

## モデルの編集

[OpenSCAD](https://openscad.org/) (Manifold バックエンド) で `lap_kit.scad` を開く。公式ケースの STL を参照するので、先に公式リポジトリを `official/` に clone しておく。

```sh
git clone https://github.com/sekigon-gonnoc/torabo-tsuki-lp official
```

調整パラメータは `lap_kit.scad` 先頭 (`splay`, `clr`, `pr_cx` など)。`part` で書き出す部品を選ぶ。

```sh
python3 build_preview.py --stl   # stl/ を書き出し直し、build/lap-kit-preview.html を作る
```

### 確認用スクリプト

- `chk.scad`: ブリッジと片側ウェッジの干渉。`t` はスライド量、`lift` は持ち上げ量。結果が空なら干渉なし。
- `chk2.scad`: 同じく、内側辺まわりに `rot` 度回したとき。
- `chk_plate.scad`: プレートと片側ウェッジの干渉。`t` は手前へ引き出す量、`lift`、`rot` (手前面まわり)。
- `gap.sh <x_off>`: 左右の最接近距離。

```sh
openscad -D 'part="none"' -D 'side="R"' -D t=30 -D lift=0.6 -o /tmp/chk.stl chk.scad
```

(`-D 'part="none"'` を付けないと、include した `lap_kit.scad` の組み立て図も一緒に出力される)
